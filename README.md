# One-person AI company — free guides

Twenty guides on running a one-person company with AI agents: workspace rules, approval gates, status notes, multiple sessions, token cost, and the store-side checks (EU checkout, catalogs, feeds).

If you want the folder itself: [One-Person AI Company Pack](https://xynex.sekai.center/order) — 39 files, 5 roles, 6 checklists, 7 prompts, 3 filled examples, EN + 中文.
